# Contributing to OptiOS

Thank you for your interest in OptiOS.

## External Pull Requests Are Not Accepted at This Stage

OptiOS is a personal learning project and a controlled empirical study in AI-assisted systems engineering ([`docs/experiment/README.md`](docs/experiment/README.md)).

To preserve both:
1. The methodological integrity of the experiment (tracking how far human-directed AI coding agents can take a bare-metal OS under the rules in [`AGENTS.md`](AGENTS.md)), and
2. Clear copyright and licensing provenance prior to any future DCO/CLA policy ([`docs/licensing-policy.md`](docs/licensing-policy.md)),

**this repository is not accepting external Pull Requests or code contributions at this time.** Any unsolicited Pull Requests will be politely closed without review.

## Bug Reports, Audits, and Discussion

While external code contributions are closed, technical feedback is welcome:
- If you spot a hardware specification bug, a kernel concurrency issue, an inaccuracy in the documentation, or a failure on physical hardware, feel free to open a **GitHub Issue** with raw reproduction logs.
- For security-sensitive findings (such as host script vulnerabilities or read-only storage bypasses), please follow [`SECURITY.md`](SECURITY.md).
- Under the terms of [`GPL-2.0-or-later`](COPYING), you are always free to fork the repository and experiment in your own tree.
